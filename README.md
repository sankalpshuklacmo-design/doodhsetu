# DoodhSetu

Milk vendor + shopkeeper daily order demo.

Shopkeepers place morning / evening orders. Vendor sees packing list and marks delivered.

## Demo login

| Role | Name | PIN |
|---|---|---|
| Vendor | राम डेयरी | `0000` |
| Shop | शर्मा जनरल स्टोर | `1111` |
| Shop | गणेश किराना | `2222` |
| Shop | माँ लक्ष्मी स्टोर | `3333` |

Open `index.html` in a browser, or use GitHub Pages after upload.

Orders save in the browser (`localStorage`). Different phones will not share the same orders until a server is added.
